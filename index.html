1. 하고 싶은 일을 적으면, 좋은 프롬프트가 됩니다

예시 버튼을 눌러보고, 내 말로 바꿔서 써보세요. 만든 프롬프트를 복사해서 챗GPT, Muse, Gemini 같은 AI에 붙여넣으면 됩니다.

여기에 만든 프롬프트가 나옵니다.

특별 기능: 한 번에 3가지 버전

같은 내용을 짧게, 초보자용으로, 전문가용으로 각각 바꿔줍니다. 상황에 맞는 버전을 골라 쓰세요.

프롬프트를 만든 뒤에 버튼을 누르면 여기에 3가지 버전이 나옵니다.

특별 기능: 영어 구조 버전

영어로 된 구조에 내 요청(한국어)을 그대로 넣어줍니다. 이미지 AI나 해외 AI에서 영어가 더 잘 통할 때 쓰세요. 완전 번역이 아니라 영어 뼈대 + 한국어 요청 조합입니다.

프롬프트를 만든 뒤에 버튼을 누르면 여기에 영어 구조 버전이 나옵니다.
왜 이렇게 만들었나요?
좋은 프롬프트는 역할, 목표, 조건, 출력 형식이 분명합니다. 이 사이트는 분야별 전문가 역할과 그 분야의 체크리스트를 자동으로 붙여서, 짧은 말도 AI가 헷갈리지 않게 바꿔줍니다.
솔직한 안내
이 버전은 서버 AI가 아니라 기기 안에서 돌아가는 전문가 구조 엔진입니다. 그래서 무료로, 로그인 없이, 인터넷이 없어도 프롬프트를 만들 수 있습니다. 진짜 AI가 직접 글을 써주게 하려면 유료 API 키가 필요해서, 그 부분은 나중에 부모님과 상의한 뒤에 연결하는 구조로 남겨두었습니다.

위 쉬운 풀이가 부족하면, 이 프롬프트를 복사해서 AI에 붙여넣으세요. 진짜 AI가 다시 쉽게 설명해줍니다.

AI 답장을 붙여넣고 버튼을 누르면 여기에 나옵니다.

3. 티키타카: AI 답장에 다시 답장하기

AI 답장이 내 마음에 100% 들지 않을 때가 많죠. 그 답장을 그대로 두고, 내 목표만 추가하면 다음 답장을 위한 프롬프트를 만들어줍니다.

여기에 답장용 프롬프트가 나옵니다.

4. 프롬프트 진단: 내 질문, 몇 점일까?

내가 평소 AI에게 던지는 질문을 붙여넣으세요. 역할, 목표, 형식, 조건, 예시, 구체성이 들어있는지 점수로 보여주고, 빠진 부분만 보완한 버전도 만들어줍니다. 다른 프롬프트 사이트에는 잘 없는, Inter Prompting만의 기능입니다.

여기에 진단 결과가 나옵니다.

5. 내 프롬프트 저장함

마음에 드는 프롬프트는 저장함에 저장해두세요. 기기 안에만 저장되고, 서버로 보내지 않습니다. 다음에 다시 쓸 때 불러와서 복사하면 됩니다.

저장된 프롬프트가 아직 없습니다. 1번 탭에서 프롬프트를 만든 뒤 “저장함에 저장하기”를 눌러보세요.

입력한 내용은 서버로 보내지 않습니다. 이 페이지는 기기 안에서만 동작합니다. 이름, 전화번호, 비밀번호 같은 개인정보는 절대 붙여넣지 마세요.
